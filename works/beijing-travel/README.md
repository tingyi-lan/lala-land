# 北京四日旅行 Web App 测试版

这是一次针对 `travel-plan-html` 新能力的前向测试产物：从一句自然语言需求生成一个可本地打开、可静态部署、带本地保存工作台的轻量旅行 Web App。

测试需求：

```text
我要去北京游玩四天，其中一天去环球影城，有拍照打卡需求。
```

## 如何打开

直接打开 `index.html` 即可查看首页，也可以用本地静态服务打开：

```bash
python3 -m http.server 8765 --directory travel-plan-beijing-test
```

然后访问 `http://127.0.0.1:8765/`。

## 这是什么形态

这是一个 static local-first travel app。共享链接打开后，所有人看到同一份基础行程；预算、预订、打包、Todo 的勾选和修改只保存在当前浏览器的 `localStorage`。除非用户导出并分享本地进度 JSON，否则这些修改不会同步到其他人或其他设备。

当前版本没有后端、账号、数据库、WebSocket 或多人实时协作，适合先部署成公开链接，再逐步迭代协作能力。

## 可部署方式

整个文件夹都是静态文件，可部署到 GitHub Pages、Vercel、Netlify、OpenAI Sites、S3 静态站点或普通 Web 服务器。部署时保持目录结构不变即可：

```text
index.html
css/style.css
js/data.js
js/main.js
data/itinerary.json
days/day01.html ... day04.html
assets/images/
```

页面使用相对路径，支持部署在子路径下。Leaflet 地图、OpenStreetMap 瓦片和 html2canvas 长图导出依赖公网 CDN；如果 CDN 或地图瓦片加载失败，核心行程仍可阅读。

## 本地进度

首页 `旅行准备工作台` 包含：

- 预算：计划总额、当前总额、分类统计、新增、编辑、删除、标记已付。
- 预订：待预订、待确认、已确认、已取消、出发前需核验。
- 打包：按分类勾选，显示进度。
- Todo：按行前阶段和每日事项勾选，突出高优先级未完成任务。

工具栏支持：

- `导出本地进度 JSON`
- `导入本地进度 JSON`
- `重置本地进度`
- `导出长图 PNG`

## 当前规划假设

- 用户未提供具体日期，本测试版按 `2026-07-12` 至 `2026-07-15` 生成。
- 同行人未指定，默认 `1-2 名成年人、中等体力、手机拍照优先`。
- 酒店默认选 `东单/王府井/前门` 一带，减少换酒店和跨城折返。
- 交通默认 `地铁 + 打车补充`。
- 北京 7 月 14-15 日高温风险较高，所以故宫、颐和园都安排早进早撤。

## 数据与来源说明

核验时间：`2026-07-11`。

已使用来源：

- 天气：北京 2026-07-12 至 2026-07-15 逐日天气预报。
- 官方核验入口：北京环球度假区官网、故宫博物院票务、中国国家博物馆、天坛公园官网、颐和园官网。
- 社交经验层：通过 OpenCLI 小红书公共搜索查询 `北京 环球影城 拍照 打卡 排队` 和 `北京 四日游 拍照 打卡 故宫 天坛 颐和园`，只提取路线、人流、排队、拍照同质化和避坑信号，没有复制笔记原文、评论、标题或图片。
- 图片：Wikimedia Commons 可访问图片链接，用于国博、天坛、环球入口、故宫午门、胡同、颐和园。

## 出发前需核验

- 环球影城开闭园时间、项目开放、票价、优速通、演出时间和当天等待时间。
- 故宫实名预约、闭馆规则、展馆票、安检和入场口安排。
- 国博预约、开放日、临展和安检要求。
- 天坛、颐和园门票、联票、停止入园时间、游船和临时关闭。
- 每日雷雨、高温、风力和交通限行。
- 酒店价格、房态、取消政策、停车、电梯、早餐、洗衣、附近药店和医院。
- 餐厅营业时间、排队、预约和人均消费。

## 缺失图片清单

当前测试版仍缺两类更能支持决策的真实图片：

- 环球影城霍格沃茨湖边机位：需要普通游客视角和下午光线图，用于判断城堡机位、人流和排队现实。
- 故宫红墙侧线：需要暑期普通游客视角，用于判断红墙机位的人流密度和避让路线。

## 如何修改行程

- 改基础行程：编辑 `data/itinerary.json` 和 `js/data.js` 中的对应数据。
- 改页面结构：编辑 `index.html`、`days/dayXX.html` 和 `js/main.js`。
- 改样式：编辑 `css/style.css`。
- 替换图片：把本地图片放到 `assets/images/dayXX/`，再把图片路径写入数据中的 `images` 数组。

## 打印与导出

浏览器可直接打印或另存 PDF。首页的 `导出长图 PNG` 会尝试用 html2canvas 捕获 `#poster` 区域；如果地图瓦片或跨域图片影响导出，请使用浏览器截图或打印。
